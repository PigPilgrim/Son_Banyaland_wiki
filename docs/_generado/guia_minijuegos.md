|---|---|

| **Clasificación** | Marca una vuelta en el modo Clasificación. |
| **3 vueltas** | Termina una carrera de 3 vueltas en solitario. |
| **Estratega** | Termina una carrera en el modo Gestión. |
| **Parada en boxes** | Haz una parada en boxes. |
| **Gomas nuevas** | Cambia de neumáticos en boxes. |
| **Todas las pistas** 🎯 | Corre en cada una de las pistas. |
| **Contra otros** | Juega una partida online. |
| **Primero en la meta** 🎯 | Gana una partida online. |
| **Gran Premio** | Corre el Gran Premio del día de la Liga. |
| **Escudería** | Únete a una escudería de la Liga. |
| **Podio** 🏆 | Acaba entre los 3 mejores de un ranking semanal de las regatas. |
| **Mi fortín** | Entra en tu fortín de Craft of Clans. |
| **Primera piedra** | Construye un edificio en tu fortín. |
| **Torreón nivel 3** | Sube el Torreón a nivel 3. |
| **Torreón nivel 5** 🎯 | Sube el Torreón a nivel 5. |
| **Recluta** | Entrena una tropa en el Cuartel. |

| **Tres estrellas** 🏆 | Consigue 3 estrellas en un ataque. |
| **Elige bando** | Elige bando para la temporada. |
| **Guerra de bandos** | Ataca en una guerra de bandos de fin de semana. |

| **Sorpresa** | Abre una caja de cabezas. |

| **Reciclaje** | Recicla cabezas repetidas. |
| **Rey de los minijuegos** 🏆 | Consigue todos los logros de esta pestaña (menos los secretos). |
