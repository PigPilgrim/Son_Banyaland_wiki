| Logro | Cómo se consigue |
|---|---|
| **Galería** | Cuelga una imagen de internet en un marco (/imageframe). |
| **Mural** 🎯 | Haz una imagen de 4 marcos o más. |
| **Taller de pintura** | Fabrica un Caballete de pintor. |
| **Primer cuadro** | Pinta un cuadro con el Caballete. |
| **Gran formato** | Pinta un cuadro de 2 × 2 mapas. |
| **Obra maestra** 🏆 | Pinta un cuadro siguiendo el trazo al 85 % o más. |
| **Estudio propio** | Fabrica un Estudio de grabación. |
| **Petición** | Pide una canción en el Estudio. |
| **Primera grabación** | Graba un disco en el Estudio. |
| **Disco de oro** 🏆 | Graba un disco Perfecto. |
| 🔒 *Secreto* | Se descubre al conseguirlo. |
| **Pon música** | Pon un disco en un tocadiscos. |
| **Música de verdad** | Pon en un tocadiscos un disco con una canción de verdad. |
| **Artista** 🏆 | Consigue todos los logros de esta pestaña (menos los secretos). |
